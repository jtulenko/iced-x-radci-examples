Remember to use this command to restart the app whenever you pull new changes from the GitHub repo:

sudo systemctl restart giamachine_app

Remember to use this command to start the virtual environment where you can install requirements/libraries/etc to the app:

source venv/bin/activate

then, while running the venv, run:

pip3 install -r requirements.txt
